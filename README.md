# でんき回路

ますに導線を置いて電池と豆電球をつなぎ、◎の豆電球だけを点ける。いちばん少ない導線の数を目指す、だれでも同じ1日3問のパズル。小学4年の理科「電流のはたらき」（直列・並列・ショート）が、遊ぶうちに身につきます。

- 遊ぶ: <https://satou-aaaaa.github.io/denki-kairo/>
- ますを押すと導線を置け、もう一度押すとはずせます。導線は上下左右のとなりの導線とつながり、電池・豆電球の両はし（口）のますにある導線ともつながります。電池の＋（左か上）から出た電気が豆電球を通って−へ戻ると、豆電球が点きます。
- 豆電球を通らずに＋と−が導線だけでつながると「ショート」で、豆電球は全部消えます（本物の電池では熱くなって危ないので、まねしないでください）。
- 豆電球はどれも同じものとして計算しています（電池1こ・豆電球1こでつないだときを「明るい」とする）。一本道に2こつなぐ（直列）と暗くなり、別々の道でつなぐ（並列）とどれも明るく点きます。×の豆電球は消したままにします。
- いちばん少ない導線の数は、盤を作るときに置き方を数えて出しています（問題の上に出ます）。その数で点けてヒントも使わなければ★3つ。
- 今日の3問（豆電球1こ5×5・2こ5×6・消したまま6×6）はだれでも同じで1日1回。上級（6×7を2つ・ヒントなし）、練習、種類ごとの記録が残る回路帳、実績があります。時間制限はありません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（盤の形や答えは入りません）。
